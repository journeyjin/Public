도안보관함 PWA 설치 안내

1. 이 폴더의 모든 파일을 같은 HTTPS 주소에 올립니다.
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
   - apple-touch-icon.png

2. iPad Safari에서 그 주소를 엽니다.

3. Safari의 공유 버튼 → '홈 화면에 추가'를 누릅니다.
   이후 홈 화면의 '도안보관함' 아이콘으로 실행합니다.

4. 처음 한 번은 인터넷이 연결된 상태에서 열어 주세요.
   PDF 읽기 기능에 필요한 PDF.js가 캐시에 저장되어 이후 오프라인에서도 사용할 수 있습니다.

데이터 유지 원리
- 도안 데이터는 PatternArchiveDB라는 IndexedDB에 저장됩니다.
- 앞으로 같은 웹 주소에서 index.html/sw.js 등의 프로그램 파일만 업데이트하면 기존 도안 DB는 그대로 유지됩니다.
- 새 기능이 추가되어 DB 구조가 바뀌더라도 기존 patterns 저장소를 삭제하지 않는 마이그레이션 방식으로 설계했습니다.
- Safari/홈 화면 앱의 사이트 데이터를 직접 삭제하거나 iPad를 초기화하면 데이터가 사라질 수 있으므로 가끔 '백업 내보내기'를 권장합니다.

기존 HTML에 이미 저장한 도안이 있는 경우
- 기존 HTML을 열어 '백업 내보내기'로 JSON 백업을 만듭니다.
- 새 PWA를 홈 화면에 설치한 뒤 '백업 불러오기'로 한 번만 가져옵니다.
- 이후에는 같은 PWA 주소를 계속 사용하면 새 버전으로 바꿔도 다시 입력할 필요가 없습니다.
